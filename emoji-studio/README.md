# Emoji Studio

Локальное приложение для Windows / macOS / Linux: берёт исходные кастомные эмодзи Telegram,
перекрашивает их, меняет ник и сохраняет готовые файлы (.tgs / .webm / .webp) на ПК.
Токен бота приложению не нужен. Исходники скачиваются через вашего Telegram-бота.

## Установка на Windows (установщик)

1. Скачайте `EmojiStudio-Setup-1.0.0.exe` из Releases репозитория (или из артефакта workflow «Build Windows installer»).
2. Запустите установщик. Права администратора не нужны, программа ставится в профиль пользователя.
3. Ярлык на рабочем столе — по желанию. Приложение откроется в отдельном окне (нужен WebView2, он есть в Windows 10/11).

Данные хранятся в `%LOCALAPPDATA%\EmojiStudio`, результаты — в `Документы\EmojiStudio\output`.

Установщик собирается автоматически: при пуше тега `v1.0.0` GitHub Actions собирает `EmojiStudio.exe` (PyInstaller), кладёт ffmpeg (для WEBM) и собирает установщик (Inno Setup, `installer/EmojiStudio.iss`).

## Запуск из исходников (для разработки)

1. Python 3.11+.
2. Для WEBM нужен ffmpeg с libvpx-vp9: положите `ffmpeg.exe` в папку `ffmpeg/` или укажите путь в `FFMPEG_PATH`.
3. `run.bat` (Windows) или `./run.sh` (macOS/Linux). Окно или браузер откроют `http://127.0.0.1:8765/`.

## Как пользоваться

**Вкладка «1. Исходники»**
1. Укажите имя вашего бота без @ и нажмите «Сохранить».
2. Нажмите «Скопировать ID и открыть Telegram». Все 94 ID попадут в буфер обмена, откроется чат с ботом.
3. Вставьте список в чат и отправьте. Бот пришлёт zip-архив с исходниками.
4. Перетащите архив в область импорта. Статус покажет, какие эмодзи готовы.

**Вкладка «2. Создать эмодзи»**
1. Введите ник (до 15 символов; только символы, которые есть в шрифте).
2. Выберите цвет тела (как в оригинале / один цвет / градиент) и цвет ника.
3. Отметьте эмодзи и нажмите «Создать эмодзи». Результат — в папке `output/<дата-время_ник>/`, там же `report.txt`.

## Бот: команда для исходников (`bot_patch/getids_admin.patch`)

Патч добавляет в `handlers/admin.py` команду `/getids` и обработку сообщения, состоящего только из ID.
Работают только для ID из `ADMIN_IDS` (ваш Telegram ID). Примените и перезапустите бота:

```
cd emoji_bot
patch -p1 < ../emoji_studio/bot_patch/getids_admin.patch   # или git apply
```

Сам бот менять не обязательно, если исходники уже есть: тогда импортируйте их вручную (`.tgs` / `.webp` / `.webm`, имена `<ID>.расширение`).

## Что важно знать

- **Надпись LOVEX.** На эмодзи, где есть надпись LOVEX (контуры из `LOVEX_BOXES` / полосы `LOVEX_BANDS`), она стирается и на её место ставится ваш ник. Другие надписи (например SCAM) не трогаются. Для эмодзи без данных LOVEX ник не ставится (см. `EXTRA_IDS` в `config.py`).
- **Калибровка ника.** Для 27 исходных эмодзи положение старого ника измерено (`NICK_BOXES` в `emoji_studio/config.py`). Для 67 дополнительных ник ищется в зоне по умолчанию, и результат нужно проверить глазами. В интерфейсе они помечены «без калибровки».
- **Проверка.** Приложение не рендерит TGS-анимацию. Откройте результат в Lottie-просмотрщике (например, lottiefiles.com/preview или Telegram Desktop через бота), прежде чем загружать в Telegram.
- **Загрузка в Telegram.** Эта версия только создаёт файлы. Сборка пака (`createNewStickerSet`) пока делается через бота, как раньше.
- Ограничения Telegram соблюдаются: TGS ≤ 64 КБ, WEBM 100×100 ≤ 256 КБ, WEBP 100×100 ≤ 64 КБ.

## Структура

```
app.py                  локальный сервер и окно приложения (pywebview)
installer/              Inno Setup-скрипт установщика и иконка
.github/workflows/      сборка установщика под Windows
web/index.html          интерфейс (без внешних библиотек)
web/assets/             картинки персонажа (вырезаны из макета)
emoji_studio/config.py  константы, калибровка, списки ID
emoji_studio/generator.py   генерация (логика как в боте)
emoji_studio/sources.py     импорт zip / файлов исходников
emoji_studio/*_recolor.py   перекраска TGS / WEBM / WEBP (из бота)
fonts/                  шрифт для ника (DejaVuSans-Bold.ttf)
bot_patch/              патч для бота: команда /getids
```
